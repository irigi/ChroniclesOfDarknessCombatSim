# VtR 2e — Conditions (Appendix Two, pp. 301–307)

Rules: resolving gives a Beat unless "Beat: n/a"; fading ≠ resolving; Persistent ones give a Beat once per session when
they bite (p. 193). Tilts (Arm Wrack, Stunned, Blinded, Immobilized, environmental) → `../cod_core/07_conditions.md`
(VtR only summarises specified-target effects, p. 178 → `05_systems.md` §15). VtR versions override core where both
exist (e.g. Swooning, Inspired). "(P)" = Persistent.
