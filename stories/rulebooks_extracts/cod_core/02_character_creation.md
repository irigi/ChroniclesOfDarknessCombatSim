# CoD core — Character creation, traits, advantages, anchors

Source: *Chronicles of Darkness* (2015 core), Ch. 1 "The Face in the Mirror" pp. 24–65
(L995–L3598). XP/Beats are in Ch. 2 p. 76 (included below). Page cites `[p. N]`.

## Creation steps (mortal) [pp. 24–27]

| Step | What | Numbers |
|---|---|---|
| 1 Concept | Short phrase + **3 Aspirations** | [p. 25, 27] |
| 2 Anchors | **Virtue + Vice** (mortals) — cannot be the same word | [p. 25, 27] |
| 3 Attributes | **1 free dot in each of 9 Attributes**; prioritise categories, add **5 / 4 / 3** | [p. 25] |
| 4 Skills | No free dots; prioritise categories, **11 / 7 / 4** | [p. 26] |
| 5 Specialties | **3** Skill Specialties (no limit per Skill) | [p. 26] |
| 6 Merits | **7 dots** | [p. 26] |
| 7 Advantages | derived, see below | [p. 26–27] |

- Attribute scale: 1 below avg, 2 avg, 3 above avg, 4 exceptional, 5 human peak [p. 25, 30].
  Skill scale: 0 untrained, 1 dabbler, 2 professional, 3 excellent, 4 outstanding, 5 world-class [p. 26].
- **No explicit creation cap on 5th dots in the core book** [interp: VtR etc. limit 5th dot; core text
  doesn't mention it — follow splat book if any].
- Several Merits are "available only at character creation": Ambidextrous, Giant, Small-Framed [pp. 47–49].

### Derived Advantages [pp. 26–27]

| Trait | Formula |
|---|---|
| Willpower (max) | Resolve + Composure |
| Integrity | starts **7** (mortals) |
| Size | **5** for adult humans (Giant 6, Small-Framed 4) |
| Health | Size + Stamina |
| Speed | Strength + Dexterity + 5 (+ species factor for animals, see 06) — meters/turn |
| Initiative modifier | Dexterity + Composure |
| Defense | lower of (Wits, Dexterity) + Athletics |
| Armor | from equipment (Appendix One) |

Defense/Initiative/Speed modifiers from Merits: Fast Reflexes +1 Init/dot; Fleet of Foot +1 Speed/dot;
Defensive Combat swaps Athletics→Brawl/Weaponry for Defense; Safe Place gives Init bonus = dots inside it.

## Attributes [pp. 30–31]
Power / Finesse / Resistance:
- Mental: Intelligence / Wits / Resolve
- Physical: Strength / Dexterity / Stamina
- Social: Presence / Manipulation / Composure

Attribute-only tasks (listed in book):
| Task | Pool | Action |
|---|---|---|
| Memorizing | Int + Composure | instant |
| **Perception** | **Wits + Composure** | reflexive |
| Catching dropped object | Wits + Dex | instant |
| Meditation | Resolve + Composure | extended (p. 75) |
| Staying awake | Resolve + Stamina | instant |
| Holding up heavy object | Str + Stamina | extended |
| Maintain balance | Dex + Composure | reflexive |
| Resisting interrogation | Stamina + Resolve | reflexive |
| Air of authority | Presence + Int | instant |
| Poker face | Manipulation + Composure | reflexive |
(Ch. 2 adds: lifting/moving = Str (+Athletics) etc., see 05_systems.)

## Skills [pp. 31–43]
**Untrained penalty: −1 for Physical & Social, −3 for Mental** [p. 31]. Specialty: +1 die [p. 31].

| Mental (−3 untrained) | Physical (−1) | Social (−1) |
|---|---|---|
| Academics | Athletics | Animal Ken |
| Computer | Brawl | Empathy |
| Crafts | Drive | Expression |
| Investigation | Firearms | Intimidation |
| Medicine | Larceny | Persuasion |
| Occult | Stealth | Socialize |
| Politics | Survival | Streetwise |
| Science | Weaponry | Subterfuge |

Sample actions (canonical pools from the book):
- Academics: recall history Int+Acad; research Resolve+Acad; translate Int+Acad.
- Computer: hack Int+Comp; net search Wits+Comp; programming Int+Comp.
- Crafts: look for flaws Wits+Crafts; design Int+Crafts; repair Dex+Crafts (wiring a radio = Dex+Crafts).
- Investigation: examine crime scene Wits+Inv; identify pattern Wits+Inv; riddle Int+Inv.
  (Investigation = active search; Perception = passive noticing.)
- Medicine: diagnosis Wits+Med; surgery Dex+Med; treat disease Int+Med.
- Occult: debunk fake Int+Occ; sliver of truth Wits+Occ; relate myths Int+Occ.
- Politics: identify authority Wits+Pol; bureaucracy Resolve+Pol; mudslinging Manip+Pol.
- Science: assess variables Int+Sci; experiment Wits+Sci; recall formula Int+Sci.
- Athletics: acrobatics Dex+Ath; **climbing Str+Ath**; **running Stamina+Ath**; thrown weapons; adds to Defense.
- Brawl: Str+Brawl in fights; breaking boards Str+Brawl; intimidating display Pres+Brawl; ID style Int+Brawl.
  Covers grappling, throws, blocking.
- Drive: pursuit Dex+Drive; stunt-flying Dex+Drive (needs **Piloting Specialty**, else untrained for aircraft); tailing Wits+Drive.
- Firearms (incl. bows/crossbows): ID gun Int+FA; firing position Wits+FA; trick shooting Dex+FA.
- Larceny: casing Wits+Larc; lockpicking Dex+Larc; sleight of hand Dex+Larc.
- Stealth: losing tail Wits+Stealth; shadowing Wits+Stealth; sneaking Dex+Stealth.
- Survival: foraging/hunting Wits+Surv; sleeping rough Stamina+Surv.
- Weaponry: any hand weapon/tool used violently; ID style Int+Weap; display Dex+Weap; size up opponent Wits+Weap.
- Animal Ken: training Composure+AK; cowing / soothing Presence+AK.
- Empathy: intentions / sense deception Wits+Emp; soothe Manip+Emp.
- Expression: poem Wits+Expr; dance Dex+Expr; speech Pres+Expr.
- Intimidation: show of force **Str+Intim**; stare down Pres+Intim; subtle threat Manip+Intim.
  (Changes behaviour, not minds.)
- Persuasion: fast talk Manip+Pers; plea Pres+Pers; seduction Manip+Pers. (Changes minds.)
- Socialize: carouse Manip+Soc; fit in Wits+Soc; get attention Pres+Soc.
- Streetwise: shortcut Wits+SW; word on street / black market Manip+SW.
- Subterfuge: conceal emotions Composure+Subt; disguise Wits+Subt; lie Manip+Subt.

## Anchors: Virtue & Vice [pp. 27–28]
- Virtue = hard to act on; Vice = easy short-term comfort. Must be personality words, not covered by an
  Attribute/Skill (no "Athletic", "Composed"), not "Good".
- Willpower regain [p. 73]: **Vice → 1 WP when a scene's actions reflect it (no risk needed); Virtue → ALL spent
  WP when acted on at difficulty/risk, up to twice per game session**. Also 1 WP per full night's sleep.
- Book examples (with regain triggers):
  - Virtues: Competitive (honestly compete vs someone who outclasses you, real stakes); Generous (deprived of
    a resource / at risk due to generosity); Just (set own goals aside so justice is done); Loyal (refusing to
    act against the group puts you at risk).
  - Vices: Ambitious (jockey for position instead of something useful); Arrogant (lord superiority);
    Competitive (indulge a competition that distracts from pressing matters); Greedy (take an advantage,
    denying it to another).
- Vice-Ridden (2 Vices) / Virtuous (2 Virtues) Merits keep the same refresh limits [p. 46].

## Aspirations [pp. 28–29]
- Start with **3**; mix short- and long-term; must be active goals. Aim ≈1 fulfilled per session.
- Fulfilling an Aspiration = **1 Beat** (p. 76); replace it after the session. Change unfulfilled ones between
  chapters with ST approval. "Fail to X" Aspirations are legal.

## Breaking points (creation questions) [pp. 29–30]
Categories: violate own moral code / social norm; witness trauma/terror/world-shaking; victim of supernatural
attack. Answer 5 questions at creation, each giving a breaking point:
1 Worst thing you've ever done? 2 Worst thing you can imagine yourself doing? 3 Worst thing you can imagine
someone else doing? 4 What have you forgotten (a past supernatural glimpse)? 5 Most traumatic thing that
happened to you? List is open-ended; ST may declare others. Self-defence killing still counts.
Mechanics → 05_systems (Integrity, p. 73–75).

## Experience & Beats [p. 76] (Ch. 2)
- **5 Beats = 1 Experience.** Dramatic failure taken voluntarily = 1 Beat (p. 69).
- Beat sources [p. 76]: fulfil an Aspiration; resolve a Condition; Condition-specific Beat triggers; turn a
  failure into a dramatic failure; **take damage in one of the 3 rightmost Health boxes**; **end of every game
  session**; **risk a breaking point** (each one).
- **XP costs** [p. 76] (flat per dot):

| Trait | Cost |
|---|---|
| Attribute | **4 Experiences per dot** |
| Skill | **2 per dot** |
| Skill Specialty | **1** |
| Merit | **1 per dot** |
| Integrity | **2 per dot** |

Willpower: not purchasable (derived = Resolve + Composure). Splat books have their own tables for powers.

## Sanctity of Merits [p. 43]
Merits lost in play (Retainer killed etc.) may be **reallocated at end of chapter**. With ST permission a
Merit can be "cashed in" for Experiences. Innate Merits (Ambidextrous, Eidetic Memory, Fighting Styles)
generally aren't cashed in. Supernatural Merits vanish if character becomes supernatural → reallocate [p. 56].

## Style Merits [p. 43]
Each dot of a Style Merit is a named maneuver; must buy in order (3-dot needs 1- and 2-dot).
