# CoD core — Dramatic systems (Ch. 2 "Infernal Engines", pp. 68–103, L3649–L5868)

Core engine for **all** CoD 2e games. Splat books override where they reprint.

## 1. Dice [pp. 68–73]
- Pool = Attribute + Skill (+ Specialty +1) ± modifiers. d10; **8, 9, 10 = success; 10 rerolls (10-again)**.
- Modifiers usually ±3, max ±5 circumstance; **add bonuses first, then penalties**. Equipment +1…+3
  (top-end +4/+5); total equipment bonus on a roll ≤ +5 [p. 69, 100].
- **Pool < 1 → chance die**: success only on 10 (no reroll); **1 = dramatic failure** [p. 69].
- Results: success ≥1; failure 0 (complications, not "nothing"); **exceptional = 5+ successes → gain a
  beneficial Condition (usually Inspired; may give it to another)**; dramatic failure = 1 on chance die, or
  **player may turn any failure into a dramatic failure for a Beat** [p. 69].
- Untrained: Mental −3, Physical/Social −1 ("muddling through") [p. 69].
- Permutations [p. 72]: **9-again**, **8-again**; **extra successes** (weapon damage added to successful
  attacks); **rote** (reroll every die that isn't 8–10, once; on chance die don't reroll a dramatic failure);
  **successive attempts** (under pressure: cumulative −1 per retry; not for extended); **teamwork** (helpers roll
  the same pool first, each success = +1 die to the primary; a helper's dramatic failure = −4 to primary).
- **No-roll rule**: don't roll when not under stress; ST should know fail & success outcomes [p. 69].

## 2. Actions [pp. 69–70]
- **Instant**: one per turn. **Reflexive**: no time, any time (most rolls to resist supernatural powers).
- **Contested**: both roll, most successes wins; ties → [interp: re-roll or status quo/defender; book
  silent here]. Exceptional judged on own total, not net. Initiator's action; resisting it is reflexive.
- **Resisted**: subtract a resistance trait (Resolve, Stamina, Composure) or Defense from the pool.
  Rule of thumb: resistance when *number* of successes matters (attacks); contested when only win/lose matters
  (e.g., thrall powers) [p. 70].
- **Extended** [p. 70]: max rolls = Attribute + Skill (+Specialty) (Patient +2). Target 5 (reasonable) /
  10 (hard, professional) / 20 (very hard). Interval set by ST (hour for a day's job, week for weeks-long).
  - Dramatic failure: fail + next attempt's first roll −2.
  - Failure: ST offers a **Condition or abandon** (refuse → lose all accumulated successes).
  - Exceptional: choose — reduce required successes by Skill dots, OR cut each later interval by ¼, OR get the
    action's exceptional effect on completion.
- **Supernatural Tolerance** (sidebar p. 70): number added to pools to resist powers — vampire Blood Potency,
  werewolf Primal Urge, etc. **Supernatural Potency** usually the same trait. Monsters in this book use
  **Rank** (ephemeral) or **Potency** (Horrors) as their Tolerance.

### Darkness
Core has **no darkness table**: use circumstance mods (dim −1 … near-dark −3); total darkness = Blind rules
(chance die on sight rolls, −3 with a substitute sense; combat → Blinded Tilt) [interp; pp. 281, 288].

## 3. Time [p. 73]
Turn (3 s) → Scene → Chapter (one session) → Story → Chronicle.

## 4. Willpower [p. 73]
- Max = Resolve + Composure. **Spend 1 WP: +3 dice to a pool, or +2 to a Resistance trait (Stamina, Resolve,
  Composure) in one roll/instance, or +2 Defense vs one attacker** [p. 73, 88, 91]. **Max 1 WP per action.**
- Regain: **1 per full night's sleep**; **Vice: 1 WP when actions in a scene reflect it** (no risk needed);
  **Virtue: all spent WP when acting on it at difficulty/risk — up to twice per game session** [p. 73].
  Other: breaking-point exceptional success (+1), surrender (+1, p. 87), True Friend, Down & Dirty exceptional.
- Killing someone when your intent wasn't harm: lose 1 WP (+ breaking point) [p. 87].
- **ST character WP budget per scene** [p. 87–88]: mooks 0; minor named 1; recurring/major antagonists up to
  half max WP. (Resolve+Composure pools unaffected; WP-drain powers work normally.)

## 5. Integrity & breaking points [pp. 73–75]
- Mortals start Integrity 7. **Buy: 2 Experiences per dot** [p. 76].
- Breaking point roll: **Resolve + Composure + Integrity modifier + situational (cap ±5)**.
  Integrity modifier: **8–10 +2 · 6–7 +1 · 4–5 0 · 2–3 −1 · 1 −2** (book table typo "1–2"; [interp] 1 = −2).
- Situational table [p. 74]: protecting self +1 · acting per Virtue +1 · protecting loved one +2 · acting per
  Vice −1 · witnessing supernatural nonviolent −1 / violent −2 · witnessing accidental death −2 · witnessing
  murder −3 · premeditated murder −5 · killing in self-defense −4 · killing by accident −4 · causing visible
  serious injury −2 · torture −3 · enduring torture −2 · enduring mental/emotional supernatural attack −2 ·
  enduring physical supernatural attack −2 · witnessing supernatural occurrence −1 to −5. (Rows overlap: apply the single most fitting witnessing modifier.)
- Results [p. 74–75]:
  - **Dramatic failure**: −1 Integrity; choose **Broken, Fugue, or Madness** (Persistent); take a Beat.
  - **Failure**: −1 Integrity; choose **Guilty, Shaken, or Spooked**.
  - **Success**: no loss; choose **Guilty, Shaken, or Spooked**.
  - **Exceptional**: Beat + regain 1 WP.
  - Also: **every breaking point risked = 1 Beat** (p. 76).
- Killing blow on helpless victim = always a breaking point [p. 94]. Human shield → breaking point (−3+ if victim dies) [p. 92].
- **Meditation** [p. 75]: extended **Composure + Wits**, target **4**, interval **30 min** (book says
  Resolve+Composure on p. 30 — [interp] p. 75 is the system text, use Composure + Wits). Success → **+1 to next
  breaking-point roll** (lost on use or sleep). Mods: music/tapes +1–+2, meditation room +3, noise/discomfort/
  no sleep −1 each, hunger −1 to −3. Meditative Mind Merit modifies.

## 6. Conditions (rules; list in 07_conditions) [pp. 75–76]
- One instance per Condition unless distinct circumstances. Sources: exceptional successes, breaking points,
  powers, ST fiat.
- **Resolving a Condition = 1 Beat** (waiting out a timed one = no Beat). ST characters resolving one: +1 WP
  for that scene instead.
- **Persistent** Conditions: long-lasting; **once per chapter, Beat when it impacts the character's life**.
- Lingering/irrelevant Conditions can be crossed off (ST may award the Beat). Improvised Conditions: ±2 dice
  to a type of action or roleplay-only effect + resolution criterion.

## 7. Experience [p. 76]
- **5 Beats = 1 Experience.** Beats: fulfil Aspiration; resolve Condition; some Conditions give Beats for
  other triggers; convert a failure to dramatic failure; **take damage in one of the three rightmost Health
  boxes**; **end of each game session**; **risk a breaking point**.
- Costs: **Attribute 4/dot · Merit 1/dot · Skill 2/dot · Specialty 1 · Integrity 2/dot** (flat).

## 8. Investigation [pp. 77–81]
- Clues = expendable equipment. Each **element = +1 die** to a relevant pool or counts toward solving.
  Clues can exceed the +5 equipment cap (limited by Investigation dots). Use elements from one Clue per action,
  or as many Clues as Investigation dots.
- Steps: 1 Scope (1–5 Clues needed for a story; chronicle: ≥½ planned chapters) · 2 Potential Clue · 3 Interval
  (fiction-based) · 4 Dice pool (any relevant Skill) · 5 Uncover.
- **Uncover a Clue** (instant; pool special; **same Skill reused = cumulative −1**):
  dram.: negative Condition + one Clue becomes **Tainted**; fail: Clue found but **Incomplete**; success: Clue
  with base element (+ extras); exc.: +1 element + a beneficial Condition (Informed/Inspired).
  Mods: scene >1 day −1, >1 wk −3, >1 yr −5; tenacious questioning +1; thorough canvassing +2; personal grudge −2;
  superstitions ±1–3; too emotionally invested −2; unrestricted access +2; tampering −1 to −5; crime matches
  Virtue +1 / Vice −2; lone investigator −1; rushed −1 to −3.
- Elements: base 1; +1 exceptional; **+1 if established by a specialist (Skill 4+ or relevant Specialty)**
  (each Skill/Specialty counts once per investigation).
- Tags: **Incomplete** (elements only aid other Uncover rolls); **Tainted** (ignore first success on all
  investigation actions, cumulative per Tainted Clue; its elements give −2 each when used).
- **Uncovering the Truth**: no roll once required Clues gathered (spend elements equal to required Clues);
  each Clue short → one complication (plausible deniability, escape plan, hostage, legal/personal risk,
  smokescreen…).

## 9. Social Maneuvering [pp. 81–84]
1. **Goal** declared; ST judges if reasonable (some goals impossible).
2. **Doors** = **lower of Resolve or Composure**; +2 if goal is a breaking point for target; +1 if it would
   prevent an Aspiration; +1 if against a Virtue. One-way between two characters. Closed Book +dots.
3. **Impression → interval** (Vice temptation / accepted soft leverage raise it a step — incl. to Excellent —
   without the Excellent roll [interp]; a willing target needn't contest Door rolls): Perfect 1 turn · Excellent 1 hour · Good 1 day · Average 1 week · Hostile can't
   roll. Good via pleasant setting (no roll first time); Excellent needs a roll (e.g., Wits+Socialize); Perfect
   needs leverage/Vice.
   - **Vice** temptation (target would gain WP) → impression +1 step. **Soft leverage** (gift/bribe, e.g.
     Resources 3) accepted → +1 step.
4. **Opening Doors**: each **successful roll opens 1 Door; exceptional opens 2**. Rolls vary (any pool that
   plausibly helps, even non-Social); target may contest/resist with Resolve/Composure etc.
   **Failed roll → cumulative −1 to further rolls** (persists); ST may also drop impression one step (player gets
   a Beat); hostile = stalled.
   - **Aspiration**: credibly offering help toward target's Aspiration removes 1 Door (no roll); reneging closes 2.
5. **Failure of whole attempt**: dramatic failure on a roll; target realizes he's being lied to/conned; hostile
   for a week (retry next story).
6. **Resolution**: final Door → ST character complies. PC targets: **comply (take a Beat)** or **offer a
   beneficial alternative** (initiator imposes a Condition on them).
- **Forcing Doors**: state goal, roll immediately with **current Doors as penalty**; target contests normally;
  success → resolution; failure → **target immune to your maneuvering**.
  **Hard leverage** (threats, drugs, blackmail, kidnapping) that is a breaking point for the *initiator*:
  removes 1 Door if that breaking-point modifier (excluding Integrity) is −2 or better, **2 Doors if −3 or worse**.
  Example: gunpoint threat = −2 → 1 Door; shooting the leg ≥ −3 → 2 Doors; roll Presence+Intimidation + gun bonus − Doors.
- **Groups**: Doors from highest Resolve/Composure; usually need Excellent impression or forcing; majority complies.
- **Successive efforts**: after success −1 Door next time; after failure or hard leverage +2; min 1 Door.

## 10. Chases [pp. 84–86]
- Each side needs **5 successes** base, modified (use only highest per category; recalc per turn):
  opponent Speed higher +1 / twice +3 / ten× +5; your Initiative mod higher −1 / 2× −2 / 3× −3; know territory −1 /
  intimately −3; Size lower than opponent −1; opponent can't tire +2; dangerous environment +1…+3; opponent has
  1-turn lead +1 / 2+ turns +2.
- Pursuer reaching target: gets **one instant action** then Initiative. Prey reaching target escapes.
- **Edge**: whoever can maneuver better; contested Wits/Dex + context Skill if unclear. Edge side picks that
  turn's dice pool (same for both) and **rolls first**. Using another pool: lose 10-again + cumulative −1.
- Chase turn = 30 s–1 min. Roll: dram. = suffer terms + Condition; fail = lose 1 accumulated success OR take a
  Tilt / 2B / 1L; success add; exc. = also inflict failure effect on opponent.
- Optional **Seizing the Edge**: both secretly predict successes; exact guess → take Edge next turn.
- Social chase: same rules with social framing.

## 11. Violence [pp. 86–95]
### Intent & surrender [pp. 86–87]
- Declare intent ("I want…") achievable by violence this scene.
- **Optional Beaten Down**: mortals (anyone with a murder breaking point) taking **> Stamina bashing or any
  lethal** gain **Beaten Down** Tilt (WP to take violent action). Can **surrender**: give attacker intent, +1 WP
  + Beat, out of fight; attacking a surrendered foe costs 1 WP (+ breaking point). Not available if the other
  side's intent is violence itself.
### Down and Dirty Combat [p. 87]
- Whole fight in one roll (PC-initiated, ST approval). Combat pool vs opponent's combat pool or escape (Str/Dex +
  Athletics); **ignore Defense**; contested. Winner deals **difference + weapon modifier** damage and gets
  intent (loser-opponent escapes if he wins as defender). Exc.: +1 WP. Dram.: opponent gets upper hand.
### Initiative [p. 88]
- Ties: book silent [interp: higher Initiative mod, then Dex, then roll off].
- **1d10 + Dex + Composure** (+ weapon's Initiative penalty while readied; two weapons: largest penalty −1 more).
  Order fixed for the fight. Drawing a weapon = instant action (Quick Draw: reflexive); dropping reflexive.
- **Delay**: act any time later; new slot persists. Delaying into the next turn forfeits that turn's action.
- **Surprise/ambush**: Wits + Composure vs attacker's Dex + Stealth; failure → no action and **no Defense
  turn 1** [p. 88].
### Attack pools [p. 88]
| Attack | Pool |
|---|---|
| Unarmed | **Str + Brawl − Defense** |
| Melee | **Str + Weaponry − Defense** |
| Ranged (guns, bows) | **Dex + Firearms** (no Defense) |
| Thrown | **Dex + Athletics − Defense** |
Damage = **successes + weapon modifier** (only if ≥1 success). **All weapons deal lethal** to humans;
fists bashing.
### Defense [p. 88]
- Lower(Wits, Dex) + Athletics; vs unarmed/melee/thrown attacks the character is aware of.
- **Each time applied, −1 vs subsequent attacks until the top of the next turn.** May choose not to apply vs
  some attacks. **1 WP = +2 Defense vs one attacker.**
- **Defense never applies vs Firearms** (exceptions: Firefight Merit; close-range guns, below).
- Sacrifice Defense for only one action per turn (All-Out Attack *or* Charge, etc.).
### Dodge [pp. 88–89]
- Instead of action (declare before your action): **roll Defense ×2** as a pool; each success subtracts one of
  the attacker's successes (before weapon modifier); 0 → no damage. Multiple attackers: reduce Defense by 1
  per attacker *before* doubling; Defense 0 → chance die. Dram.: −1 Defense next turn. Only when Defense applies.
### Unarmed specials [pp. 89–90]
- **Bite**: human −1 weapon mod, bashing, **only in a grapple via Damage move**. Animals: lethal; wolf +1,
  great white +4.
- **Disarm**: Str + Brawl vs Str + Athletics (contested; Defense not subtracted); success → drops weapon; exc. → you take it; dram. → you take damage
  = weapon modifier.
- **Grapple**: grab = **Str + Brawl − Defense**; success → both grappling (exc.: pick a move immediately).
  Each later turn: **contested Str + Brawl vs Str + Brawl on the higher Initiative of the two**; winner picks
  **one move (two on exceptional)**:
  [interp — RAW silent:] the contest is each grappler's action for the turn; moves like Hold persist until a later
  winner changes them; a tie = no move; third parties attack grapplers normally in melee (shooting in: −4) and
  can't add teamwork dice to the contest.
  - Break Free (reflexive; may then act) · Control Weapon (draw own / turn his) · **Damage** (bashing =
    successes; + weapon mod **only after winning a Control Weapon move**, even for a knife already
    in hand [RAW p. 89–90]; human bite via this) · Disarm (needs Control Weapon first) ·
    Drop Prone (both; must Break Free before rising) · **Hold** (neither can apply Defense vs incoming attacks) ·
    **Restrain** (needs prior Hold; **Immobilized** Tilt; with gear — tape, zip ties, rope — the move
    applies it, no extra roll, and you may leave the grapple; **handcuffs** are a separate grapple option: Str + Brawl −
    opponent's Str [p. 275]; escaping bindings: Str + Athletics − Durability (07), cuffs per 03) · Take Cover
    (opponent as shield; ranged attacks this turn hit him).
- **Touching**: Dex + Brawl/Weaponry, Defense applies, no damage [p. 90, 91].
### Ranged specials [pp. 90–92]
- **Aim**: instant action → +1 next shot, cumulative to +3 (Marksmanship more); lost if you apply Defense;
  not with autofire.
- **Autofire**: short burst 3 rounds, +1, one target; medium 10 rounds, +2, 1–3 adjacent targets; long 20
  rounds, +3, any targets. Multiple targets: **−(number of targets)** to pool [text p. 90] (summary chart says
  −1 per target after the first [p. 91]; [interp] use text: −N), one roll per target.
- **Covering fire** (full-auto only, 10 rounds): Dex + Firearms on an area; success → each target on next action
  must run to cover within Speed / drop prone, or act normally and take successes + weapon mod damage.
- **Firearms in close combat**: guns larger than Size 1 → target's Defense applies **+ (gun Size + 1)**;
  long guns used as clubs = improvised crowbar.
- **Range**: medium **−1**, long **−2** [text p. 90] (summary chart p. 91 says −2/−4; [interp] use text);
  beyond long = chance die. Thrown range: short = Str + Dex + Athletics − object Size (yd/m), ×2 medium, ×4 long;
  aerodynamic ×2 each (long = (Str+Dex+Ath)×8). Can only throw Size < Strength.
- **Concealment** (penalty to shooter): barely −1, partially −2, substantially −3. Firing back from concealment:
  own penalty −1 less (0/−1/−2).
- **Cover** (fully hidden): if cover Durability > weapon modifier → can't penetrate; else subtract Durability
  from damage (transparent: half, round down); object and target both take remaining damage.
- **Shooting into close combat**: −2 per combatant avoided (−4 if grappling); not autofire.
- **Human shield**: Durability = victim's Stamina + armor; victim takes all damage; breaking point.
- **Reload**: instant action; loose rounds → no Defense that turn; magazine/speedloader keeps Defense.
### General factors [pp. 92–94]
- **Movement**: Speed and still act; give up action → move 2× Speed.
- **Charge**: sacrifice Defense, move up to 2× Speed + Brawl/Weaponry attack (not if Defense already used).
- **Going prone**: ranged/thrown −2 vs you; standing melee attackers +2. Dropping or rising costs the action.
- **All-Out Attack**: sacrifice Defense, **+2 Brawl/Weaponry** (not if Defense already applied this turn).
- **Offhand**: −2. **Pulling blows**: set max damage ≤ higher trait in attack pool; defender +1 Defense; ST may
  allow 1 WP for a weapon to deal bashing.
- **Specified targets**: torso −1 · arm −2 (damage > Stamina → Arm Wrack) · leg −2 (> Stamina → Leg Wrack) ·
  head −3 (damage ≥ Size → Stunned) · heart −3 (≥5 damage pierces heart; special vs monsters) · hand −4 (Arm Wrack) ·
  eye −5 (Blinded). Specified targets can ignore armor (p. 94 "Armor") [interp: ST judges if the location is unarmored].
- **Killing blow**: target unconscious/immobile/defenseless → damage = **full dice pool + weapon modifier**
  (no roll), ignores armor; breaking point regardless.
- **Surprised / Immobilized target: no Defense.** Prone target: ranged −2, close +2.
- **Tilts**: combat-only Conditions, no Beats; list in 07_conditions.
### Weapons & armor [p. 94]
- Weapon modifier = bonus successes on hit; add it to pool when weapon helps otherwise (chain to grapple, gun
  to intimidate). Charts in 06/Appendix (see 03_equipment).
- **Improvised**: use nearest profile, else damage = Durability − 1, Initiative penalty & Strength req = Size;
  **−1 to attack**; weapon takes the same damage it deals (minus its Durability); Structure 0 = wrecked.
- **Armor**: **ballistic** (vs firearms) — each point downgrades 1 lethal → bashing; **general** (all attacks)
  — each point removes 1 damage, most severe first. Apply ballistic first. **Lethal attack vs armor always
  leaves ≥1 bashing** ("shock").
- **Armor piercing N**: subtract from ballistic first then general; in close combat only general; vs objects/
  cover: subtract from Durability.
- Strength requirement: below it → −1 per point short [interp — stated on weapon chart p. 268; see 03_equipment].
### Injury & healing [pp. 95–96]
- Health boxes = Stamina + Size. Bashing `/`, lethal `X`, aggravated `*`; most severe to the left, push lesser right.
- **Wound penalties** (all actions incl. Initiative, not Stamina-to-stay-conscious): 3rd-to-last box marked
  **−1**, 2nd-to-last **−2**, last **−3**.
- **Full track**: filled with bashing → further bashing/lethal upgrades leftmost bashing to lethal; rightmost box
  bashing → **reflexive Stamina roll each turn to stay conscious**. Rightmost box lethal → **1 more damage per
  minute** (upgrading lethal → agg) until medical help (bleeding out). All aggravated → **dead**.
- **Temporary Health boxes**: damage in them rolls into real boxes when effect ends.
- **Natural healing** (rightmost first): **bashing 1 per 15 min · lethal 1 per 2 days · aggravated 1 per week**.
  Bleeding out (full lethal) can't heal without urgent care.
- **Medical care** [p. 96]: extended, successes = total damage points; field/ER **Dex + Medicine**, 1 min
  interval; hospital **Int + Medicine**, 1 hr. Success heals **1 extra bashing** point. Medical attention **stops the bleeding-out** per-minute damage
  [p. 95]. Kit: first-aid kit • permits field treatment, •• +1 (stacks with Specialty); no kit → ST may forbid or
  penalise; self-treatment penalty not in core [interp −2]. **Intensive care**
  (hospital): Int + Medicine extended, 1 hr/roll, **5 successes downgrade a lethal → bashing, 10 an agg →
  lethal**, worst first, max 1 per day of treatment.
### Objects [p. 96]
- **Durability** subtracted from damage (not vs aggravated): 1 wood/hard plastic/thick glass, 2 stone/
  aluminum, 3 steel/iron, +1 per reinforced layer. **Structure = Durability + Size**; damage > Durability → −1
  to use; 0 = destroyed. No bashing/lethal distinction. Demolisher ignores Durability.

## 12. Sources of harm [pp. 96–98]
- **Disease**: reflexive Stamina + Resolve (± severity) per interval; 1 success avoids damage.
- **Drugs**: reflexive Stamina + Resolve (± potency) per hour/scene/turn; overdose = poison Toxicity 3–7
  hourly (beer/wine 3 … rubbing alcohol 5; bad heroin 7 for (8 − Stamina) hours).
- **Electricity** (bashing per turn, no roll; armor useless): wall socket 4B · protective fence 6B · junction
  box 8B · main line/subway rail 10B. Continuous source: reflexive **Strength** roll each turn to let go.
- **Extreme environments**: level 0–4 = penalty to all actions; after **Stamina hours**, 1 bashing/hour
  (level 3: lethal); level 4: lethal **each turn after Stamina turns**. Levels 2–4 scar; no healing until safe.
  (1: light snow/too cold to sleep/1st-degree sun; 2: heavy snow, hypothermia risk, minor radiation;
  3: desert, rapid 2nd-degree burns, moderate radiation; 4: sandstorm, hurricane, tornado, tsunami.)
- **Falling**: **1 bashing per 3 m** (lethal if onto spikes/glass); **≥30 m terminal = 10 lethal flat**.
  Dex + Athletics: each success −1 damage (not at terminal velocity).
- **Fire**: lethal per turn, no roll = **Size (torch 1, bonfire 2, inferno 3) + Heat (candle 0, torch +1,
  Bunsen +2, chemical/molten +3)**. Persisting >1 turn ignites combustibles (keeps burning off-source).
  Extinguisher/hose −1 size per turn. Armor blocks its general rating in fire damage for turns = rating.
- **Poison**: lethal = **Toxicity** (once, per turn, or per hour); reflexive **Stamina + Resolve − Toxicity**,
  each success −1 damage, every time it deals damage.

## 13. Vehicles [pp. 98–99]
| Vehicle | Dice mod | Size | Dur/Str | Speed |
|---|---|---|---|---|
| Motorcycle | −1 | 7 | 2/9 | 100 |
| Compact car | −2 | 8 | 3/11 | 90 |
| Family car | −3 | 12 | 3/15 | 80 |
| Sports car | −1 | 10 | 2/12 | 140 |
| Limousine | −4 | 20 | 3/18 | 60 |
| Van | −3 | 18 | 3/21 | 80 |
| Pickup | −2 | 15 | 4/19 | 80 |
| SUV | −2 | 15 | 4/19 | 100 |
| Motorboat | −2 | 10 | 2/12 | 60 |
- Dice mod applies to Dex + Drive. Structure damage ≥½ → −2 to operate; ≥¾ → −5.
- Speed = safe speed; accelerate **+5 Speed/turn** (High Acceleration +10); Dex + Drive (+dice mod): each success
  +5 more (Slow Acceleration can't). Up to 1.5× Speed: dice mod applied again as extra penalty; failed maneuvers
  = dramatic; turning >45° = maneuver roll or overturn (crash).
- Mods: up to 2×Crafts mods, 4 h each (+1 dice mod max +5; +2 secondary bonus; +0.5 Size; +0.5 Durability max 5;
  +2 Structure; +5 Speed; remove Slow Accel (3 mods); add High Accel (2)).
- **Crash vs light object (≤ ½ vehicle Size)**: object takes **Speed/10 + ½ vehicle Size** bashing; driver
  Dex + Drive or vehicle takes ½ object Size + Speed/10; damage beyond vehicle Durability → occupants bashing
  (halved by seat belts/airbags). Deliberately hitting: Dex + Drive − Defense, successes add to victim damage.
- **vs heavy object (> ½ Size)**: each takes **½ the other's Size + relative Speed/10** (head-on/perpendicular:
  add Speeds; parallel: subtract). Each driver Dex + Drive: each success −2 damage. Excess over Durability →
  occupants bashing (halved by safety gear).

## 14. Equipment & building [pp. 100–103]
- Availability (dots) = Resources cost, Social Merit level to find it, or Skill level to get it with one roll.
- Max +5 total equipment bonus.
- **Build Equipment** (instant, may take minutes–hours): physical Wits + Crafts (creative Wits + Expression);
  organization Pres/Manip + Socialize/Streetwise; repository Int + Academics; mystical Wits + Occult; **plan
  Wits + Composure** (bonus to everyone involved, ends when plan succeeds/fails).
  **Penalty = intended bonus** (each extra function = 1; weapon = its modifier; armor = highest rating; max −5).
  No roll if unhurried and Skill dots ≥ bonus. In action scenes takes turns = penalty.
  Results: dram. consequence; fail = built but **Fragile** (breaks after uses = Skill dots) or **Volatile**
  (any failure with it = dramatic; afterwards −2 bonus); success; exc. +1 bonus/benefit.
- **Jury rigging**: same pool, instant, no build time; **any failure = dramatic**; success = Fragile/Volatile;
  exceptional = normal item.
